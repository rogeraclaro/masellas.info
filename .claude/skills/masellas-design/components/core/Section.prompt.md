Full-viewport, single flat color slide with vertically centered content — the site's only layout unit.
```jsx
<Section tone="coral"><Heading>Roger Masellas</Heading><Paragraph>…</Paragraph></Section>
<Section tone="dark"><div><Paragraph variant="intro">…</Paragraph></div></Section>
```
- `coral` (#f4624e, centered) or `dark` (#272525, left). Never gradients, never images.

# masellas.info — website UI kit
Recreation of the root site of `rogeraclaro/masellas.info` (index.html + css/styles.css + fullPage.js 3.0.3 config, qr.html).
- `FullPage.jsx` — continuous-vertical slide controller (wheel / arrows / menu), 700ms ease like fullPage defaults.
- `CoverSection.jsx` — #section0 "the point" (coral).
- `WordsSection.jsx` — #section1 "some words" (charcoal bio).
- `QrScreen.jsx` — qr.html. The "qr" button bottom-right is a kit-only affordance to reach it (not on the live site).
PDF CV links point to `#` (PDFs are not in the repo).
